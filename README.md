# G2S3: Gaussian Grouping Semantic Segmentation using SAM​

We introduce G2S3, a 3D scene segmentation pipeline that combines semantic segmentation from SegFormer with Gaussian Grouping, guided by the Segment Anything Model (SAM). Applied to the Replica and ScanNet++ datasets, our method produces 3D instance masks with explicit semantic labels. We assess segmentation quality using Intersection over Union (IoU) across 20 predefined semantic classes.​
